# Dashboard - Verification Analytics & Audit Logs

A modern web interface for viewing verification history, inspecting detailed claim evaluations, and reviewing aggregate analytics on hallucination patterns across generative AI models.

## Features

- **Overview Metrics**: Total responses verified, claim counts, hallucination rate, average confidence.
- **Verification History**: Searchable and filterable history of verified responses.
- **Claim Inspector**: Deep dive into individual claims, retrieved evidence snippets, NLI classification, and semantic similarities.
- **Model Comparison Analytics**: Comparison of hallucination rates and accuracy across ChatGPT, Gemini, and Claude.
